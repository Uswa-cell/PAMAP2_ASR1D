# Energy-Efficient Neural Networks Using Adaptive Sparsification

## Datasets Analyzed

### 1. PTB-XL (Cardiac ECG)
- 15,000+ ECG signals
- 71 diagnostic statements
- [Figures](figures/) - 8 visualizations
- [Notebook](PTB-XL_Adaptive_Sparsification.ipynb)

### 2. PAMAP2 (Activity Recognition)

- [Notebook](PAMAP2_ASR1D.ipynb)

- 62% energy reduction (PTB-XL)
- Maintained accuracy with adaptive routing
